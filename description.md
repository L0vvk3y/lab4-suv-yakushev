# Описание проекта

В репозитории отрабатываются синхронизация копии с GitHub и обсуждение изменений через pull request.

Изменения предлагаются отдельной веткой, проверяются перед слиянием и затем получаются в main.
Этот пример выполняется индивидуально: комментарий к PR является самопроверкой автора.
